# Runtime audio provenance

Only the files that the game currently loads are retained under `assets/audio/`.

| Runtime collection | Origin / status |
| --- | --- |
| `groups/LIKE/攻击音效组/` | Ten sword sounds from [20 Sword Sound Effects (Attacks and Clashes)](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes), released as [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The verified source archive checksum was `f363c80ea1627548d336370750651b0d2d092978148ecfb3642717c2efb54b6b`; the archive itself was removed after selection because it is not loaded by the game. |
| Other files in `groups/LIKE/` | Current user-selected runtime clips. Keep their original licensing information with the source supplied by the project owner. |
| `music/` | Local conversions provided by the project owner. They are not CC0 assets; obtain distribution rights before publishing a build. |

The former seven experimental CC0 style packs and their raw archives were removed because no runtime code or test references them.
