# Runtime Audio Library

This folder contains only audio that the game currently loads. Unused source archives and experimental style packs are intentionally excluded from the repository so they cannot inflate exports.

- `groups/LIKE/` contains the selected interface, card and sword sounds.
- `music/` contains the locally provided background-music conversions.
- `LICENSES.md` records the provenance retained for the CC0 sword clips.

No existing television, film, anime, game recording, character voice, melody, or imitation of a signature franchise sound may be added to this library.
