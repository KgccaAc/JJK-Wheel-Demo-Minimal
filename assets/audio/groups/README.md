# Active sound selection

`LIKE/` is the only active runtime sound group and must be retained.

`AudioManager.gd` loads its click, card, discard, confirmation and sword clips directly from this directory. `LIKE/攻击音效组/` contains the ten interchangeable sword-impact variants used after battle card resolution.

The previous seven full experimental style packs were removed after the reference audit: they were not loaded by the game or by acceptance tests.
