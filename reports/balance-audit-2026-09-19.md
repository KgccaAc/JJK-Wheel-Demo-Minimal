# 手牌战斗平衡性审计（2026-09-19）

## 结论摘要
当前手牌不好玩不是单一伤害数值问题，而是四个系统问题叠加：
1. AP 是历史设计残留：虽然旧规则和 351 张牌曾携带 AP，当前 V3 从未把它作为真实资源使用；继续保留会误导数值策划和玩家，因此已从卡牌、模板和实例化流程清理。
2. 手牌规模与弃牌节奏不一致：deal_round 每回合生成 10 张，固定弃 2 张；规则文件又同时存在 8 张上限、每回合抽 5、保留手牌等原型语义。
3. 牌面费用与真实费用可能不一致：DSL 的 compute_action_value(costCe,set) 会覆盖 JSON cost.ce；例如苍卡面 CE20、DSL实际30，赫卡面CE50、DSL实际60。
4. 牌池功能密度过高：cards.json 共351张，静态 damage=0 有217张，其中117张不是 support；35张含状态/计数器/选择前置，14张依赖动态计算。

## 当前实现基线
- 规则源：data/battle/source/rules.json、runtime/hand-rules.json、resource-rules.json。
- 发牌：BattleFlowSession.deal_round；正常手牌10张，basic/technique按池比例采样，领域牌独立最多3张，固定弃2张。
- 出牌：V3检查正常牌选择上限、CE、前置与领域最多1张；不再检查 AP。
- 结算：ActionResolverV3先执行DSL，再算角色维度、策略、领域、状态、V3防御和护盾。
- AI：choose_cpu_play主要按 damage + healing*0.6 + block*0.5 - ce*0.15 排序；没有AP、命中、组合、状态、后续回合价值。

## 牌池统计
351张牌：support 103（CE32.44、静态伤害0.99，100张零伤害）；attack 107（CE42.92、伤害51.80，6张零伤害）；summon 32（CE40.88、伤害10.44，9张零伤害）；defense 78（CE37.04、伤害0.91，76张零伤害）；domain 24（CE38.29、伤害12.24，19张零伤害）；healing 5；resource 2。
299张含 atomicEffects；35张含 require/consume/selection 前置；14张含动态数值；risk 为 medium 297、high 53、critical 1。

## 玩家视角根因
新手：10张手牌加固定弃2再选最多3，首先要判断哪些牌能用，而不是做组合；卡面费用与真实费用不一致会破坏资源直觉；大量零静态伤害牌缺少即时收益提示。
熟练玩家：所有牌目前都只占一个选牌位；最优线容易退化为挑三张静态分高的牌；策略、角色、术式、领域、易伤/减伤的独立乘法边界不透明。

## 公开资料与可迁移原则
1. Game Mechanics Hoard 的 Mana Curve（https://gamemechanicshoard.com/mechanic/mana-curve/）：费用曲线要让每个阶段都有可行动选择；过高费会导致早期无牌可出，过低费会后期乏力。
2. Game Design GG 的 Card and Board Game Design（https://gamedesign.gg/articles/card-and-board-game-design/）：卡差与节奏是两个维度；每回合都在立即压力和保留未来选项之间交换。
3. 该资料对 Hearthstone、Slay the Spire、Legends of Runeterra 的比较：稳定曲线、少量可读关键词和清晰系统规则，比每张牌都拥有独立前置更容易形成策略。
4. 公开伤害公式讨论的共同原则：同类增益先加算，少量真正独立来源再乘算；多个独立乘区叠加会造成爆发失控。

## 三套候选方案
### A 无 AP 基线修复（当前执行）
移除旧 AP 字段和校验；统一卡面与 resolved CE；保留10张发牌和固定弃2，先用真实 CE/前置/组合统计建立基线；AI加入 CE、组合价值、命中和状态价值。优点是与当前战斗一致、避免半成品资源规则；缺点是10张仍偏宽。
### B 中度重构
最终可见8张，发5张新牌，未使用牌按保留规则进入下一轮；弃牌只处理溢出或主动换牌；1/2 AP真实生效；每手保证至少2张即时可行动牌和1个主题组件。优点是决策更集中；缺点是会改变弃牌、回合和联机协议。
### C 主题构筑试点
每名角色先做12到16张主题小牌池，按基础/准备/兑现/防守/终结模板配比；角色属性影响基础层，术式组件进入加算槽，领域与易伤保留少量独立乘区。优点是主题感最好；缺点是内容制作量最高。

## 推荐乘区
最终伤害 = Base ×（1 + 角色/策略同类加算）× 状态乘区 × 领域乘区 → 防御/护盾。
角色/策略同类总加成先合并并封顶约 ±35%到±45%；易伤/减伤合并为单一状态乘区并限制约0.70到1.35；领域只保留一个独立乘区并承担负荷代价；必中、暴击、无视防御作为稀有规则，不与所有增伤常驻相乘。

## 首轮验收指标
- 首回合10张中至少6张可在当前资源/前置下使用，至少2种决策类型。
- 当前 CE 预算下至少2种合法组合，不能总是单张最高静态伤害。
- 卡面 CE 与 resolved preview 差异为0，或明确标注基础/预计。
- 固定种子20局，连续两回合无法行动比例低于5%。
- 角色主题牌首回合出现率20%到40%。
- 最高与中位伤害倍率比值先控制在2.5到3.0。
- 联机 revision/phase/winner 全程一致，平衡改动不改变服务器权威协议字段。
