## 修改边界检查

1. 本轮未新增普通 `Button`，未绘制临时灰色按钮。
2. 后续新增按钮只能使用 `TextureButton` 或项目已有纹理按钮组件，并从 `art/` 选择纹理。
3. 正式服务 `https://119.91.224.223/` 与预览后端 `https://119.91.224.223/preview/` 不做部署、配置、重启或数据写入。
4. 旧路径 `scenes/fight`、`scenes/onlineroom` 暂不删除，避免破坏兼容链；先完成生产路径验收再合并。

1. 转盘抽取 → 身份确认 → 角色保存 → 基础战斗
2. 转盘角色快照 → 角色选择 → 基础战斗发牌与结算
3. 联机房间 → 角色锁定 → strategy/discard/initiative/play → FINISHED
4. 故事模式继续作为完整回归链，不替代上述核心链路
