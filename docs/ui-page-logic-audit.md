## 交互反馈策略

- 底部导航统一使用普通/紫色选中两套纹理，并补充悬停与点击缩放动画。
- 故事页面使用统一的悬停、键盘焦点和点击缩放反馈。
- 转盘、首页、社区、联机和角色列表保留各自已有的专属动画。
- 目前多数 TextureButton 没有独立 `texture_hover` / `texture_pressed` 美术资源，运行时动画已提供可感知反馈；将来补图时可直接覆盖，不需要改业务逻辑。
