# 联机服务器选择弹窗设计

## 目标

让新手知道当前是在选择联机环境，让熟练玩家能快速切换；弹窗必须融入联机页面的纸张/黑红视觉，不出现 Godot 默认灰色面板或普通 `Button`。

## 视觉与交互

- 使用 `art/onlineroom/房间页面/服务器选择.png` 作为弹窗面板的 `StyleBoxTexture`，通过九宫格边距保持边框比例。
- 标题显示“选择联机服务器”，并在按钮文字中明确“本地 Mock · V3 8789”和“官方联机服务器 · HTTPS”。
- 两项操作继续使用 `TextureButton`，复用 `按钮1.png`/`按钮2.png` 的正常、悬停和按下状态。
- 选择后立即隐藏弹窗、刷新页面当前服务器文本，并保留原有 endpoint 切换逻辑。

## 后端验收边界

- 只访问 `https://119.91.224.223/preview/` 与 `https://119.91.224.223/preview-room-api`。
- 只读健康探测，以及预览房间创建、WebSocket 双端战斗同步验收。
- 不访问或写入正式根服务，不部署、不重启、不迁移正式服务。

## 验收证据

- 真实窗口截图：弹窗无默认灰框、标题可读、按钮可点且有悬停/按下纹理。
- `OnlinePopupRealWindowAcceptance.gd`：节点、纹理、点击后的 `_server_index` 和截图均通过。
- 预览后端脚本：健康、HTTP 建房、WebSocket 双端战斗均通过。
